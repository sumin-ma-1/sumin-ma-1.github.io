Hello, I am a researcher at the Korea Electronics Technology Institute (KETI) and conduct research with the Autonomous Mechanical Systems (AMS) Lab at Sookmyung Women’s University, where I received my B.E. in IT Engineering.

My research focuses on how computer-use agents can execute tasks reliably and efficiently across software environments, even when unexpected events disrupt execution. In my current work, I investigate which steps from a successful run can be reused as code and which decisions require a language model at runtime. I evaluate this approach across variations of the same task by measuring task success, the number of model calls, and execution time.

At KETI, I build agents for workplace workflows. I design how these agents clarify incomplete requests, carry out tasks across software tools, and show users what actions they took.

With a background in computer science and experience in applied research, I hope to build on this work through doctoral research. I’m particularly interested in how computer-use agents can verify outcomes and recover from failures with fewer model calls, and how they can recognize when to seek human input.

Selected Research

Trajectory-Based Agent Execution

  • Built a framework that compiles reusable operations from computer-use trajectories into code and uses LLM calls for semantic decisions.
  • Ongoing evaluation measures task success, model calls, and latency on held-out task variations.

GUI Grounding from User Descriptions

  • Analyzed 508 referring expressions from 22 participants and found that 81.7% combined multiple cues.
  • Developed a grounding ranker with same-target alignment that raised top-1 accuracy from 40.9% to 46.7%.

Visual Fallback for Single-Step GUI Control

  • Trained a YOLOv9-S icon detector on synthetic screenshots to support single-step desktop control when accessibility metadata was missing or insufficient.
  • Evaluated icon size, density, and distractors. Including icon-like distractors during training raised ScreenSpot mAP@50 from 0.327 to 0.579.
